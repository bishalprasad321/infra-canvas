# 08.1 - Non-Implemented & Mocked Features

## Current Placeholders & Mocked Logic

To help engineers target their efforts effectively, this document identifies features that are currently mocked or only partially implemented in the codebase.

---

### 1. OS Environment Selector (Canvas Header)
- **Current Status**: **Mocked UI State**.
- **Location**: `apps/web/app/workspace/page.tsx` (Linux, macOS, Windows button group in header).
- **Behavior**: Toggles component local state in the UI but has no downstream effect on code generation options, target Ansible task syntax, or shell command generation.
- **Future Work**: Connect the selected OS to Ansible module variants (e.g. `apt` for Debian/Ubuntu vs `yum`/`dnf` for RHEL/CentOS vs `homebrew` for macOS).

---

### 2. OAuth Account Management UI
- **Current Status**: **Backend Functional / UI Incomplete**.
- **Location**: `apps/api/oauth.go`.
- **Behavior**: The login and signup OAuth 2.0 flow works completely. However, there is currently no user settings view to view linked providers, link a secondary provider to an existing password account, or unlink an existing provider.
- **Future Work**: Add an "Account Security & Connected Identities" tab inside user profile settings.

---

### 3. Billing & Stripe Webhook Integration
- **Current Status**: **Schema Present / Mock Upgrade Route**.
- **Location**: `apps/api/main.go` (`handleUpgradePlan`).
- **Behavior**: Users can switch plans via the `/api/auth/upgrade` endpoint directly, but real Stripe checkout sessions, invoice webhooks, and subscription lifecycles are not yet connected.
- **Future Work**: Integrate Stripe Checkout / Customer Portal and enforce hard limits on Free tier usage.

---

### 4. Snapshot Rollback & Revision History UI
- **Current Status**: **Database Table Ready (`canvas_snapshots`)**.
- **Location**: Database schema contains `canvas_snapshots` table with `commit_message`, `nodes_json`, `edges_json`.
- **Behavior**: Snapshots are created on specific events, but the visual timeline and "Revert to this revision" action in the canvas header is not yet wired up.
- **Future Work**: Build a visual history drawer with one-click revision restore.
