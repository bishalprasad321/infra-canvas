# 06.1 - InfraCanvas CLI & Reverse Import Tool

## Cross-Platform Command Line Interface

The **InfraCanvas CLI** (`infracanvas`) is a standalone command-line tool written in Go that connects terminal workflows directly to the visual canvas.

```mermaid
graph TD
    CLI[infracanvas CLI] --> CMD_Login[infracanvas login]
    CLI --> CMD_Projects[infracanvas projects list]
    CLI --> CMD_Import[infracanvas import --file main.tf --project-id ...]
    CLI --> CMD_Deploy[infracanvas deploy --project-id ...]
    CLI --> CMD_Destroy[infracanvas destroy --project-id ...]

    CMD_Import --> API[Go API /api/projects/{id}/import]
    API --> AST[Reverse Importer AST Parser]
    AST --> WS[Broadcast Workspace WS Update]
    WS --> Browser[Active Browser Canvas Updates Instantly]
```

---

## CLI Command Reference

### 1. `infracanvas login`
Prompts for user email and password, validates against `POST /api/auth/login`, and stores the issued JWT token in `~/.infracanvas/config.json`.

### 2. `infracanvas projects list`
Lists all accessible projects across teams with their IDs and visibility settings.

### 3. `infracanvas import`
Reverse-parses local Terraform or Ansible files into visual canvas nodes:
```bash
infracanvas import --project-id proj_abc123 --file ./terraform/main.tf
```
The backend parses the HCL AST, arranges the blocks via the Vertical Phase Rows layout algorithm, saves the state, and broadcasts a WebSocket sync event so any user with the canvas open sees the imported nodes appear in real time.

### 4. `infracanvas deploy` & `infracanvas destroy`
Triggers remote runner pipelines from CI/CD scripts or developer terminals, streaming logs directly into the terminal output.
