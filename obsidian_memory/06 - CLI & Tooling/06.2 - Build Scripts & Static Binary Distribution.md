# 06.2 - Build Scripts & Static Binary Distribution

## Local Build Pipelines

InfraCanvas includes automated cross-compilation build scripts for distributing CLI binaries locally and in CI.

### PowerShell Build Script (`build_cli_local.ps1`)
```powershell
$outputDir = "./apps/api/static/downloads"
if (!(Test-Path $outputDir)) {
    New-Item -ItemType Directory -Path $outputDir -Force
}

# Windows AMD64
$env:GOOS = "windows"; $env:GOARCH = "amd64"
go build -o "$outputDir/infracanvas-windows-amd64.exe" ./cmd/cli

# Linux AMD64
$env:GOOS = "linux"; $env:GOARCH = "amd64"
go build -o "$outputDir/infracanvas-linux-amd64" ./cmd/cli

# macOS ARM64 (Apple Silicon)
$env:GOOS = "darwin"; $env:GOARCH = "arm64"
go build -o "$outputDir/infracanvas-darwin-arm64" ./cmd/cli
```

## Static Download Serving with GitHub Fallback

The Go API serves CLI downloads from the route `GET /downloads/{filename...}` (`apps/api/main.go`):
1. **Local Disk Check**: Checks `./static/downloads/<filename>`. If the pre-compiled binary exists, it serves the file directly with `http.ServeFile`.
2. **GitHub Releases Fallback**: If the file does not exist locally (e.g. running in minimal container environments), it responds with `307 Temporary Redirect` to:
   `https://github.com/bishalprasad321/infra-canvas/releases/latest/download/<filename>`.
