# 01.2 - System Architecture & Monorepo Structure

## High-Level System Architecture

InfraCanvas is structured as a **Turborepo monorepo** consisting of a **Next.js 16 web application** frontend and a **Go 1.23 API and execution engine** backend.

```mermaid
graph TB
    subgraph Browser Client
        UI[Next.js App / React 19]
        RF[ReactFlow Canvas @xyflow/react]
        ZS[Zustand Stores: Canvas & Auth]
        CG[Client-Side Compilers<br/>bundleGenerator.ts & exportYaml.ts]
    end

    subgraph Go API Backend [apps/api]
        HTTP[HTTP REST API / Mux Router]
        WS_Run[Gorilla WS Run Streaming]
        WS_Room[Gorilla WS Room Collaboration]
        AUTH[JWT & OAuth Engine]
        VAL[HCL & YAML AST Validators]
        RUNNER[Runner Execution Engine]
        VAULT[AES-256-GCM Credential Vault]
        DB[(SQLite DB dev.db)]
    end

    subgraph DevOps Sandbox [sandbox/]
        LS[(LocalStack 4566)]
        SSH1[(Ubuntu SSH Target 1 :2222)]
        SSH2[(Ubuntu SSH Target 2 :2223)]
    end

    UI <-->|HTTP REST| HTTP
    UI <-->|WebSocket :8080/api/ws/runs/{id}| WS_Run
    UI <-->|WebSocket :8080/api/workspace/{id}/sync| WS_Room
    
    HTTP --> AUTH
    HTTP --> VAL
    HTTP --> VAULT
    HTTP --> DB
    
    HTTP -->|Trigger Deploy / Destroy| RUNNER
    RUNNER -->|Exec Terraform & Ansible| LS
    RUNNER -->|SSH Commands via id_rsa| SSH1
    RUNNER -->|SSH Commands via id_rsa| SSH2
    RUNNER -->|Log Stream & Status Events| WS_Run
```

## Technology Stack Breakdown

| Layer | Technology | Version | Rationale & Architectural Choice |
| :--- | :--- | :--- | :--- |
| **Monorepo Manager** | Turborepo | `^2.x` | Orchestrates concurrent dev servers (`web` + `api`) with cached build pipelines. |
| **Frontend Framework** | Next.js (App Router) | `16.0.7` | High-performance React framework with server-side rendering and client-side routing. |
| **UI Library** | React | `19.0.0` | Latest React version with concurrent rendering and modern hook primitives. |
| **Visual Node Engine** | `@xyflow/react` | `^12.4.4` | Modern ReactFlow library providing high-performance canvas, pan/zoom, handles, and custom node rendering. |
| **Client State** | Zustand | `^5.0.3` | Lightweight, un-opinionated state management without Context boilerplate. |
| **Code Highlighting** | PrismJS | `^1.30.0` | In-browser syntax highlighting for HCL, YAML, and shell scripts. |
| **ZIP Compilation** | JSZip | `^3.10.1` | In-memory archive packager for instant client-side download of generated DevOps bundles. |
| **Backend Core** | Go | `1.23` | High concurrency, fast compilation, small memory footprint, ideal for process spawning and streaming. |
| **Database** | SQLite (`modernc.org/sqlite`) | `v1.36.0` | Pure Go SQLite driver without CGO dependencies; ensures zero cross-platform build failures on Windows/Linux. |
| **WebSockets** | Gorilla WebSocket | `v1.5.3` | Robust Go WebSocket implementation for real-time log streaming and room collaboration. |
| **Cloud Sandbox** | LocalStack | `latest` | Mock AWS services (VPC, EC2, S3, RDS) allowing full Terraform apply tests locally. |
| **Server Sandbox** | Ubuntu SSH Docker | `custom` | Dedicated containers running `sshd` simulating physical/virtual deployment targets for Ansible. |

## Monorepo Pipeline (Turborepo)

The root `turbo.json` defines task execution dependencies:

```json
{
  "$schema": "https://turbo.build/schema.json",
  "tasks": {
    "build": {
      "dependsOn": ["^build"],
      "outputs": [".next/**", "!.next/cache/**", "dist/**"]
    },
    "dev": {
      "cache": false,
      "persistent": true
    }
  }
}
```

Running `npm run dev` at the repository root launches:
1. `apps/web` on `http://localhost:3000`
2. `apps/api` on `http://localhost:8080`
