# 05.1 - ReactFlow Canvas & Interaction Modes

## Interactive Visual Viewport

The primary user interface of InfraCanvas is a hardware-accelerated infinite viewport built on **`@xyflow/react` (ReactFlow v12)** in `apps/web/app/workspace/page.tsx`.

Users can pan, zoom, drag nodes from the sidebar catalog, connect output-to-input handles, and configure parameters in real time.

```mermaid
graph TD
    Toolbar[CanvasControls Toolbar] --> ModeCheck{Active Canvas Mode}
    
    ModeCheck -->|Select Mode (V)| SelectBehavior[Node Dragging Enabled<br/>Box Multiselect Enabled<br/>Link Drawing Active]

    ModeCheck -->|Link Mode (L)| LinkBehavior[Node Dragging Disabled<br/>Handles Pulsing Violet Glow<br/>Crosshair Mouse Cursor]
```

## Interaction Modes (`CanvasControls`)

The canvas toolbar provides three interaction modes:

### 1. Select Mode (`'select'`)
- **Default State**: Full visual editing.
- Clicking a node opens its configuration in `NodeConfigPanel`.
- Dragging nodes updates coordinates in local Zustand state.
- Dragging on empty background draws a selection bounding box for multi-selecting blocks.

### 2. Pan Mode (`'pan'`)
- **Navigation Focused**: Designed for large architectural graphs.
- Disables node dragging and link handle drawing.
- Clicking and dragging anywhere (including directly on node bodies) pans the canvas viewport.
- Mouse cursor changes to `grab` / `grabbing`.

### 3. Link Mode (`'link'`)
- **Wiring Focused**: Designed for connecting multiple dependencies without shifting node positions.
- Disables node movement.
- Connection handles expand and pulse with an enlarged violet glow.
- Hovering over a handle shifts the color to cyan.
- Mouse cursor changes to `crosshair`.

## Key Canvas UI Components

| Component File | Location | Responsibility |
| :--- | :--- | :--- |
| `ReactFlowCanvasNode.tsx` | `apps/web/app/components/` | Custom node card rendering icon, label, technology tag, handle anchors, delete action, and execution status strip. |
| `Sidebar.tsx` | `apps/web/app/components/` | Draggable node catalog organized into categories (Compute, Database, Network, Storage, System). |
| `NodeConfigPanel.tsx` | `apps/web/app/components/` | Parameter inspector for configuring active node properties (CIDRs, ports, instance sizes). |
| `RightPanel.tsx` | `apps/web/app/components/` | Tabbed code viewer rendering live-compiled Terraform HCL, Ansible YAML, and K8s YAML with syntax highlighting. |
| `CredentialManagerModal.tsx` | `apps/web/app/components/` | Modal for creating and attaching AWS/GCP/SSH keys to the project. |
| `CustomNodeModal.tsx` | `apps/web/app/components/` | Modal for authoring and validating user-defined HCL/YAML blocks. |
| `ProjectSettingsModal.tsx` | `apps/web/app/components/` | Project settings, visibility controls, member roles, and invitation management. |
