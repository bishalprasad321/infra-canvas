# 07.2 - Technical Pitfalls & Edge Cases

## Non-Obvious Traps & Edge Cases

This document details subtle behaviors and traps across the codebase that engineers must account for before writing new features.

---

### 1. Dependency Cycles in ReactFlow Connections
- **The Pitfall**: Users can create circular connection edges on the visual canvas (e.g. Node A -> Node B -> Node A).
- **The Impact**: Standard Kahn topological sort stalls and produces empty task lists or crashes.
- **The Defense**: `apps/web/app/lib/exportYaml.ts` detects when `sortedIds.length < nodes.length`. It appends any remaining unvisited nodes in their original array index order, ensuring the generated playbook never drops nodes.

---

### 2. Secret Redaction Order in Runner Logs
- **The Pitfall**: Replacing short substrings (e.g. 1-2 character strings) in `SecretRedactor` corrupts normal log words (e.g. replacing `in` in `Creating...` -> `Cr********g...`).
- **The Defense**: `SecretRedactor` enforces `len(s) > 3` before attempting `strings.ReplaceAll()`. Secrets are sanitized and sorted by descending length before masking.

---

### 3. Docker Compose Networking vs Local Host IP
- **The Pitfall**: When running the API server directly via `go run main.go` on the host machine, LocalStack is reached at `http://localhost:4566`. When running the API inside Docker via `docker-compose.yml`, LocalStack is reached at `http://localstack:4566`.
- **The Defense**: The runner checks the `IS_DOCKER` environment variable. If `IS_DOCKER == "true"`, it replaces `localhost` with the container service name `localstack` in generated Terraform endpoint blocks.

---

### 4. Optimistic Concurrency Overwrite Clashes
- **The Pitfall**: If User A and User B have the canvas open simultaneously, User B's auto-save could overwrite User A's changes.
- **The Defense**: `canvas_states` includes an incrementing `version INTEGER`. Updates with stale versions receive HTTP `409 Conflict`, signaling the frontend to reload.

---

### 5. GitHub Private Email Setting
- **The Pitfall**: When a GitHub user has "Keep my email addresses private" enabled in their GitHub profile, `GET /user` returns `email: null`.
- **The Defense**: `oauth.go` requests the `user:email` scope and explicitly issues a secondary call to `GET https://api.github.com/user/emails` to find the verified, primary email.

---

### 6. Next.js 16 App Router Breaking Conventions
- **The Pitfall**: Next.js 16 has breaking changes compared to earlier versions (e.g. async `params` in dynamic routes, revised turbopack behavior).
- **The Defense**: Check `node_modules/next/dist/docs/` before altering App Router page layouts.
