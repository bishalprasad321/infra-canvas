# 07.3 - Design Trade-offs & Pros-Cons Matrix

## Architectural Decisions & Trade-Offs

Every technical decision in InfraCanvas balances complexity, developer ergonomics, security, and performance. This matrix records rationale, chosen options, and accepted trade-offs.

---

## Core Trade-Offs Analysis

| Decision Area | Option Chosen | Alternative Considered | Pros of Chosen Option | Cons / Accepted Limitations |
| :--- | :--- | :--- | :--- | :--- |
| **Database Engine** | **Pure Go SQLite** (`modernc.org/sqlite`) | PostgreSQL / MySQL | • Zero external setup for local dev.<br/>• Zero CGO compilation errors.<br/>• Fast single-file embedded DB. | • Single-writer concurrency limits.<br/>• Not suited for horizontally scaled multi-node clusters without LiteFS/D1. |
| **Code Generation** | **Client-Side in Browser** (`bundleGenerator.ts`) | Server-Side API generation | • Real-time preview with 0ms network latency.<br/>• Offline and instant zip download.<br/>• Zero backend CPU cost. | • Duplication of some parser structures between TS and Go.<br/>• Client CPU handles large graph compilation. |
| **State Management** | **Zustand** | Redux / React Context | • Minimal boilerplate.<br/>• No top-level Provider re-render cascade.<br/>• High performance with ReactFlow. | • Requires discipline to avoid direct state mutation outside store actions. |
| **Live Log Streaming** | **In-Memory Go WebSockets** | Redis Pub/Sub / SSE | • Zero external infrastructure dependencies.<br/>• Native bi-directional communication.<br/>• Simple goroutine management. | • Run logs held in Go process memory; server restart drops active in-flight streams. |
| **Social Login Storage** | **Dedicated `oauth_identities` table** | Boolean flags on `users` table | • Decoupled identity model.<br/>• Unlimited providers per user.<br/>• Zero future DB migrations for new OAuth. | • Requires JOIN queries during authentication lookup. |
| **Sandbox Execution** | **LocalStack + Docker SSH** | Real AWS Free Tier | • Free and offline capable.<br/>• Zero risk of accidental cloud bills.<br/>• Fast container resets. | • LocalStack does not mock 100% of AWS API edge cases. |
